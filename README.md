# TG Автоответчик — неограниченное число аккаунтов (для Bothost.ru)

Бот подключает **сколько угодно рабочих аккаунтов Telegram**: достаточно положить файл
сессии `accN.session` в папку `data/` (или задать строку-сессию). У каждого аккаунта —
**свой текст автоответа** и вкл/выкл, всё управляется через твоего админ-бота в Telegram.

Пакет готов к развёртыванию на [bothost.ru](https://bothost.ru) (long polling,
без вебхуков и интерактивного ввода).

---

## 🚀 Деплой на Bothost.ru

1. **Зарегистрируйся** на bothost.ru и создай проект **Telegram Bot**.
2. Загрузи **архив этого проекта** (или подключи Git-репозиторий).
   Главный файл — `main.py`.
3. В настройках бота задай **переменные окружения**:

   | Переменная | Описание |
   |------------|----------|
   | `BOT_TOKEN` | задаётся **автоматически** при создании бота на bothost |
   | `ADMIN_ID` | твой Telegram ID (узнать у @userinfobot) |
   | `API_ID` | число, с my.telegram.org/apps |
   | `API_HASH` | строка, с my.telegram.org/apps |

   Опционально: `MAX_ACCOUNTS`, `COOLDOWN` (сек), `DEFAULT_REPLY`.
4. Нажми «Деплой».

> Файлы и настройки аккаунтов хранятся в папке `data/` (на bothost это `/app/data` —
> сохраняется между обновлениями кода).

## ➕ Как добавить рабочий аккаунт

Способ **1 — файл сессии** (удобнее всего):
1. Локально на ПК выполни `python gen_session.py` и выбери режим `1`.
2. Загрузи файл `acc1.session` (или `acc2.session`, …) в папку `data/` **через
   файловый менеджер** панели bothost.
3. Напиши своему админ-боту `/scan` — аккаунт подключится.

Способ **2 — строка-сессия**:
1. Локально выполни `python gen_session.py` и выбери режим `2`.
2. Скопируй выведенную строку в переменную окружения `ACC1_SESSION` (для других аккаунтов
   — `ACC2_SESSION`, `ACC3_SESSION`, …).
3. Перезапусти бота или отправь `/scan`.

Можно смешивать: сколько файлов положил — столько аккаунтов работает.

## 🎛 Панель управления (админ-бот)

Всё управление — кнопками. Открой бота и нажми `/start` (или "Запустить"):

| Кнопка | Что делает |
|--------|------------|
| 📋 Аккаунты | список аккаунтов (со страницами); нажми на номер — откроется панель аккаунта |
| ✅ Включить / ⛔ Выключить | вкл/выкл автоответ конкретному аккаунту |
| ✏️ Изменить текст | бот попросит: просто напиши ему новый текст — он станет автоответом |
| 📝 Текст всем | один текст всем аккаунтам сразу |
| ✅/⛔ Включить все / Выключить все | массовое вкл/выкл всех аккаунтов |
| 🔄 Сканировать | подключить новые сессии без перезапуска |
| 📊 Статус | сводка: онлайн, включено, ошибки, аптайм |
| ❓ Помощь | подсказка по кнопкам |

## 🧪 Локальный запуск (для проверки)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# настройки в переменных окружения или файле .env
API_ID=... API_HASH=... BOT_TOKEN=... ADMIN_ID=... python main.py
```

## 📁 Структура

```
main.py            # точка входа (bothost запускает именно его)
config.py          # настройки из env / .env
accounts.py        # поиск сессий: файлы accN.session + строки
config_store.py    # сохранение текстов и вкл/выкл (data/autoreply_config.json)
engine.py          # подключение юзерботов и автоответ
handlers.py        # команды и меню админ-бота
keyboards.py       # inline-кнопки
gen_session.py     # создание сессии (файл или строка)
requirements.txt
Dockerfile         # опциональный кастомный образ
data/              # сюда кладутся acc*.session (НЕ теряется при обновлениях)
```

## ⚠️ Безопасность

Файлы `*.session` и строки-сессии дают полный доступ к аккаунту. Не загружай их в
публичный Git, не передавай никому. Папка `data/` уже в `.gitignore`.
